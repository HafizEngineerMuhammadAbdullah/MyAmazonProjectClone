# 🛍️ Amazon Homepage Clone

A responsive frontend clone of the Amazon homepage built using HTML and CSS.
This project focuses on layout design, navigation structure, and UI replication of a real-world e-commerce platform.

---

## 🚀 Features

* 🧭 Fully structured navigation bar:

  * Logo
  * Delivery location
  * Search bar
  * Account & Orders
  * Cart section

* 📂 Multi-section panel navigation

* 🖼️ Hero section with promotional banner

* 🛒 Product category grid (shop section)

* 🎨 Hover effects for better UI interaction

* 📱 Responsive layout using Flexbox

* 🔗 Footer with multiple sections and links

---

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **Font Awesome** – Icons
